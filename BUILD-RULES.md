- Clusters ONLY: gut, hair, deficiency. Every article: sources listed, "डॉक्टर को कब दिखाएं" red-flag box, educational framing.

- NEVER claim doctor review until a real named medical reviewer exists. The reviewer-line UI shows the sources basis honestly.
- Tools 100% client-side; health inputs never leave the browser. BMI uses Indian cut-offs.
